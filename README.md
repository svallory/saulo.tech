# saulo.tech

Hub site for Saulo Vallory's projects: a curated list of open-source work with an image, a short description, and links to the repo, docs, and package for each.

Built with [Marko 6](https://markojs.com) and [@marko/run](https://github.com/marko-js/run) (static adapter), styled with Tailwind v4, using [marko-ui](https://marko-ui.saulo.tech) components. Deployed at <https://saulo.tech>.

## Development

Bun only, never npm.

```bash
bun install
bun run dev      # local dev server
bun run build    # static export
```
